# 🎰 Jackpot – Slot Machine Game

## 📌 Overview
Jackpot is a casino-style slot machine game developed using **Unity 6 and C#**. Players spin three reels, match symbols, earn coins, and manage their bets.

## 🎮 Features
- Three randomized slot reels.
- RNG-based symbol selection.
- Coin balance and betting system.
- Increase, decrease, and maximum bet options.
- Two matching symbols: 1.5× payout.
- Three matching symbols: 2× payout.
- All different symbols: No reward.
- Custom casino-themed UI.

## 🛠️ Technologies
- Unity 6
- C#
- TextMeshPro
- Unity UI System
- Coroutines

## ▶️ How to Run
1. Clone or download the repository.
2. Open the project in Unity Hub.
3. Open the `MainGame` scene.
4. Press Play.
